# Occam’s Razor

## Core idea

When explanations account for the evidence equally well, prefer the one requiring fewer assumptions.

Source: [Occam’s Razor — Laws of UX](https://lawsofux.com/occams-razor/).

## Apply in context

As a design heuristic, compare equally capable solutions and remove elements that add no useful function. For example, replace a separate configuration step with a clear, editable default when it meets the same needs.

## Use judgment

Equally capable is the key condition. Removing labels, recovery, or necessary controls may merely transfer complexity to the user.

## Check the experience

Remove or simplify an element in a prototype. Can people still understand, complete, and recover from the task with comparable confidence?
