# Chunking

## Core idea

Related pieces become easier to process when they form meaningful units.

Source: [Chunking — Laws of UX](https://lawsofux.com/chunking/).

## Apply in context

Group by the user's task or vocabulary. For example, organize a registration form into identity, delivery, and payment, with labels that explain each group's purpose.

## Use judgment

A visual box alone does not create meaningful organization. Arbitrary groups or extra pages can add navigation and separate information needed together.

## Check the experience

Ask someone to locate and explain a group. Check whether they can find information without opening several unrelated sections.
