# Zeigarnik Effect

## Core idea

Unfinished or interrupted tasks may remain more memorable than completed ones.

Source: [Zeigarnik Effect — Laws of UX](https://lawsofux.com/zeigarnik-effect/).

## Apply in context

Support a useful return to unfinished work. For example, save a draft and show the remaining step when someone returns.

## Use judgment

Remembering unfinished work does not guarantee motivation to finish it. Preserve an easy way to pause or dismiss work; reminders should support a goal the user still wants.

## Check the experience

After an interruption, can someone identify what is unfinished and resume it? Check whether reminders are helpful or merely create a sense of obligation.
