# Paradox of the Active User

## Core idea

People often start doing their task immediately, even when learning the tool first could save later effort.

Source: [Paradox of the Active User — Laws of UX](https://lawsofux.com/paradox-of-the-active-user/).

## Apply in context

Place guidance where an action needs it and provide a useful first task. For example, an empty automation editor can offer an editable example with explanations beside its controls.

## Use judgment

The tendency is not literally universal. Keep deeper learning available for complex work and make consequential prerequisites visible before action.

## Check the experience

Let a new user begin from their likely entry point without a tour. Can they reach a useful result and find help when they need it?
