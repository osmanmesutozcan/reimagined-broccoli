# Law of Proximity

## Core idea

Nearby elements tend to be perceived as related.

Source: [Law of Proximity — Laws of UX](https://lawsofux.com/law-of-proximity/).

## Apply in context

Use relative spacing to express relationships. For example, place a field's help and error text closer to that field than to the next input.

## Use judgment

Responsive layouts can accidentally regroup elements. Visual closeness also needs appropriate semantic association for nonvisual use.

## Check the experience

Ask which field an error describes and which item an action affects. Repeat with wrapping text and a narrow viewport.
