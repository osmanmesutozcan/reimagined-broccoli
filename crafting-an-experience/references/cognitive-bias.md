# Cognitive Bias

## Core idea

Mental shortcuts help people decide quickly but can systematically skew judgment, including the designer's judgment.

Source: [Cognitive Bias — Laws of UX](https://lawsofux.com/cognitive-bias/).

## Apply in context

Inspect how defaults, labels, ordering, and prior beliefs shape interpretation. For example, evaluate a recommended plan against user needs and actively seek cases where the recommendation is wrong.

## Use judgment

A bias label is a hypothesis about a mechanism, not a diagnosis of an individual. Support informed choice with visible consequences and alternatives.

## Check the experience

Use neutral task prompts and seek disconfirming observations. Would the design still seem successful if a user chose a different option for a sound reason?
