# Tesler’s Law

## Core idea

Some task complexity persists and must be handled by the user or the system.

Source: [Tesler’s Law — Laws of UX](https://lawsofux.com/teslers-law/).

## Apply in context

Identify necessary decisions and move predictable work into the system. For example, infer a likely timezone while exposing it for review and correction.

## Use judgment

Automation may hide consequential assumptions or create difficult exceptions. Preserve user control where the system cannot reliably infer intent.

## Check the experience

Trace each necessary decision: who handles it, on what evidence, and how is a wrong assumption corrected? Test an exception as well as the common path.
